# 🧪 UI-тесты для проекта QA Desk

Автоматизированные UI-тесты для веб-приложения [QA Desk](https://qa-desk.stand.praktikum-services.ru), написанные на **Python + Selenium + Pytest**.

---

## 📂 Структура проекта

```
Sprint_5/
│
├── tests/                      # Тестовые сценарии
│   ├── test_login.py           # Авторизация
│   ├── test_logout.py          # Выход из профиля
│   ├── test_registration.py    # Регистрация
│   └── test_create_ad.py       # Создание объявления
│
├── conftest.py                 # Фикстуры pytest (драйвер, логин и т.д.)
├── helpers.py                  # Вспомогательные функции и методы
├── locators.py                 # Локаторы для всех страниц
├── data.py                     # Тестовые данные и конфигурация
└── README.md                   # Документация проекта
```

---


## 🧰 Фикстуры

Фикстуры описаны в `conftest.py`:

| Фикстура | Описание |
|-----------|-----------|
| `driver` | Инициализирует WebDriver (Chrome). После теста браузер закрывается. |
| `login` | Авторизует тестового пользователя перед запуском теста. |

Пример использования:

```python
def test_create_ad_with_authorized_user(driver, login):
    ...
```

---

## 🧩 Хелперы (`helpers.py`)

Содержит статические методы:
- `random_email()` — генерация уникального email  
- `random_password()` — генерация случайного пароля  
- `random_ad_name()` / `random_ad_description()` / `random_ad_price()` — генерация данных для объявлений  
- `go_to_last_page(driver)` — пролистывает пагинацию до последней страницы  
- `extract_price("45 345 ₽")` → `45345` — извлекает число из строки

---

## 🗺️ Локаторы (`locators.py`)

Все локаторы собраны в один класс `Locators` для удобного переиспользования:

```python
class Locators:
    LOGIN_BUTTON = (By.XPATH, "//button[text()='Войти']")
    INPUT_EMAIL = (By.XPATH, "//input[@type='email']")
    ...
```

## 🧾 Тесты

| Файл | Назначение |
|------|-------------|
| `test_registration.py` | Проверяет успешную регистрацию, невалидные email и дубликаты |
| `test_login.py` | Проверяет вход с корректными и некорректными данными |
| `test_logout.py` | Проверяет корректный выход из аккаунта |
| `test_create_ad.py` | Проверяет создание объявления (авторизованный / неавторизованный пользователь) |
